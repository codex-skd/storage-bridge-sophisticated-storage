<h2>v0.0.0-beta.1 - First beta</h2>

<p>First public build of <strong>Storage Bridge (Sophisticated Storage)</strong>. Right-click a Sophisticated Storage Controller to route items that Sophisticated Storage can't store for you.</p>

<h3>Features</h3>
<ul>
<li><strong>Apothic-Enchanting Library</strong>: enchanted books go into a reachable Library (<code>apothic_enchanting:library</code> / <code>apothic_enchanting:ender_library</code>).</li>
<li><strong>Apotheosis Gem Case</strong>: unsocketed gems go into a reachable Gem Case or Ender Gem Case.</li>
<li><strong>Network reach</strong>: the target can touch the Controller, any storage connected to it, or a Storage Link, within Sophisticated Storage's <code>controllerRange</code>.</li>
</ul>

<p>Trigger: right-click the Controller with your main hand, not sneaking, on any face. Sophisticated Storage's own inventory deposit still happens on the same click.</p>

<h3>Notes</h3>
<blockquote>Sophisticated Storage (+ Sophisticated Core), Apothic-Enchanting and Apotheosis + Placebo are all <strong>required</strong> dependencies.</blockquote>
